O que este mockup propõe

Tudo aqui é proposta para a Fase 14 (arquitetura §5.13). Nada foi decidido além do que a v0.20 registra.

Mandar comandos pelo celular

  • O chat abre direto: é a primeira aba e o composer fica embaixo, ao alcance do polegar.
  • Para quem: o topo e a linha “Para” mostram o destinatário. Um toque troca entre o Orquestrador global e o Diretor de cada cenário.
  • Comandos rápidos: fichas acima do composer, que mudam com o estado do cenário (com peça rodando: Como está?, Pausar, Nova peça…).
  • / comandos: uma folha com busca, agrupada em Peça, Criar e Consultar, mais as Minhas frases salvas.
  • Voz: sem texto, o botão grande é microfone; segure para falar. Com texto, vira enviar. O ditado do teclado do Android também funciona a confirmar.
  • Modelos com “…” preenchem o texto para você completar; os outros enviam na hora.
  • Ações destrutivas (cancelar) pedem confirmação e biometria.
  • Sem VPN: a mensagem fica na fila do aparelho e sai quando a conexão volta. Teste com “Simular sem VPN”.
  • Decisões com um toque, no chat e na aba Decisões, com contador na navegação.

Celular: o que fica de fora

  • Editar Executores, papéis, perfis, plugins e ordens; o DAG desenhado; trajetórias longas; o navegador compartilhado. Aparecem só para leitura, com aviso de abrir no computador.

Tablet

  • Paisagem: o layout do app.html (lateral, chat, painel em abas), com alvos de toque maiores.
  • Retrato: o chat ocupa a tela; ☰ abre a lateral e ▤ abre o painel, como gavetas.
  • Edita a configuração completa, como a web.

Ideias para depois

  • Compartilhar com o OTheater a partir de outro app (texto, link, foto), indo para o chat escolhido.
  • Widget na tela inicial ou bloco nas configurações rápidas: “Falar com o Diretor”.
  • Notificação com ações: responder a uma decisão sem abrir o app (depende do item 19).
