# Third-party notices (ot-job-launcher)

`ot-job-launcher` is licensed under MPL-2.0 (see the repository `LICENSE`). This file lists the
Rust crates linked into the Windows binary, taken from `Cargo.lock` with
`cargo metadata --locked --offline --format-version 1` (verified locally, 2026-11-16). The
repository-level `THIRD_PARTY_NOTICES.md` covers the npm packages and is generated by
`pnpm notices`; this one is kept by hand until both are unified (see README.md, "Maintenance").

| windows-link | 0.2.1 | MIT OR Apache-2.0 | https://github.com/microsoft/windows-rs |

Both crates are dependencies of the Windows build only (`[target.'cfg(windows)'.dependencies]`).

(https://github.com/rust-lang/rust; stated by the Rust project, not re-verified here).
